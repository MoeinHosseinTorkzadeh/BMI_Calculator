BMI Calculator

A Flutter application that calculates Body Mass Index (BMI) based on a user's height and weight. The app provides BMI classification and stores previous calculations locally using SQLite.

Features
Calculate BMI
Select gender
Adjust height, weight, and age
Display BMI category and result
Save BMI history using SQLite
View previous BMI records
Clean and responsive UI
Built With
Flutter
Dart
SQLite (sqflite)
path
path_provider
Getting Started

Clone the repository:

git clone https://github.com/MoeinHosseinTorkzadeh/BMI_Calculator.git

Navigate to the project:

cd BMI_Calculator

Install dependencies:

flutter pub get

Run the app:

flutter run
